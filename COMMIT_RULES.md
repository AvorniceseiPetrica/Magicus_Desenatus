Commits done to this project should respect the following:

    [type]([scope]):[commit message]

[type] = The type of commit done. Examples include: feat = feature, fix = fixes, docs = documentation etc.<br>
(optional) [scope] = The areas where changes have been made. This can either be an entire module or a single file.<br>
[commit message] = A short text that explains what has changed.
